## 專案簡介

本專案以台灣內政部「不動產成交案件實際資訊資料供應系統」（實價登錄）提供的台北市買賣交易原始資料為基礎，建立一套完整的資料清洗 → 地理編碼 → 特徵工程 → 機器學習預測管線。

**分析目標：** 預測台北市住宅物件的每坪成交價格（單位：新台幣）

**資料範圍：**
- 地區：台北市全區
- 時間：民國 111 年 Q1 ～ 114 年 Q2（2022–2025 年）
- 物件類型：住宅用途不動產買賣（排除非住宅、特殊關係人交易）

**模型表現：**
| 指標 | 數值 |
|------|------|
| R²（決定係數） | **0.833** |
| MAPE（平均絕對百分比誤差） | **8.62%** |
| MAE（平均絕對誤差） | 58,829 TWD/坪 |
| 5-Fold CV R² | 0.836 ± 0.004 |

## 腳本說明

### `process_real_estate.py` — 資料清洗與篩選

**功能：** 讀取內政部原始 CSV 資料，清洗並篩選出符合條件的住宅交易紀錄。

**篩選邏輯：**
- 僅保留「房地（土地＋建物）」或含車位的交易
- 排除「特殊關係」交易（親屬、員工等）
- 排除「公設保留地」
- 主要用途限定為「住家用」
- 排除工業、農業用地
- 排除純車位、純土地交易

**衍生欄位計算：**
- `每坪價格` = (總價 − 車位總價) ÷ (建物面積 ÷ 3.30579)
- `坪數` = 建物移轉面積平方公尺 ÷ 3.30579
- `車位坪數` = 車位面積平方公尺 ÷ 3.30579
- `屋齡` = 交易年份 − 建築完成年份
- `是否有電梯` = 1/0（二元化）
- `幾樓` = 從「移轉層次」欄位解析（處理中文數字）

**使用方式：**
```bash
python process_real_estate.py
```

**輸入：** `data/台北市不動產和預售屋買賣資料/原始資料/{年份}/Q{季}/`
**輸出：** `data/台北市不動產和預售屋買賣資料/整合/資料篩選/{年份}/`

---

### `geocode_yearly.py` — 地址地理編碼

**功能：** 將房屋地址轉換為經緯度座標，以供後續地理分析使用。

**技術細節：**
- 使用 `geopy` 套件連接 ArcGIS Geocoding API
- 每次 API 請求間隔 0.5 秒（避免超過速率限制）
- 本地快取機制：已查詢過的地址不重複呼叫 API
- 自動處理全形字元轉半形（如「５０」→「50」）
- 從地址字串解析樓層資訊（支援中文數字如「一樓」→「1」）

**使用方式：**
```bash
python geocode_yearly.py 111   # 處理民國 111 年資料
python geocode_yearly.py 112
python geocode_yearly.py 113
python geocode_yearly.py 114
```

> 注意：地理編碼需要網路連線，且每筆查詢間隔 0.5 秒，每年約需數小時。

**輸入：** `整合/資料篩選/{年份}/{年份}.csv`
**輸出：** `整合/新增座標/{年份}座標.csv`

---

### `find_nearest_mrt.py` — 最近捷運站距離計算

**功能：** 為每筆房屋資料計算至最近捷運站出口的直線距離。

**演算法：**
- 使用 Haversine 公式計算球面距離（單位：公尺）
- 以台北捷運 388 個出入口為參考點
- 每筆資料對應輸出：最近出入口名稱 ＋ 距離（公尺）

**使用方式：**
```bash
python find_nearest_mrt.py 111
python find_nearest_mrt.py 112
python find_nearest_mrt.py 113
python find_nearest_mrt.py 114
```

**輸入：**
- `整合/新增座標/{年份}座標.csv`
- `data/臺北捷運車站出入口座標.csv`

**輸出：** `整合/含捷運站距離/{年份}座標_最近捷運站.csv`

---

### `rf_analysis.py` — Random Forest 模型訓練與評估

**功能：** 合併所有分類資料，訓練 Random Forest 迴歸模型預測每坪價格，並輸出完整的評估指標與特徵重要性。

**資料前處理：**
- 合併 20 個分類 CSV 檔（約 35,801 筆）
- 類別變數編碼（Label Encoding）：`交易標的`、`類別`、`年份`
- 數值缺失值補中位數：`幾樓`、`屋齡`、`坪數`、`車位坪數`、`緯度`、`經度`、`距離`
- 去除極端值（目標變數前後 1%）→ 保留 35,085 筆
- 訓練集/測試集 = 80% / 20%

**模型設定：**
```python
RandomForestRegressor(
    n_estimators=200,    # 決策樹數量
    max_depth=20,        # 最大深度
    min_samples_leaf=5,  # 葉節點最小樣本數
    random_state=42,
    n_jobs=-1            # 使用全部 CPU 核心
)
```

**評估指標：** MAE、RMSE、R²、MAPE、5-Fold 交叉驗證

**使用方式：**
```bash
python rf_analysis.py
```

**輸入：** `整合/分類篩選/*.csv`（共 20 個檔案）
**輸出：** `rf_results.json`

## 模型結果

### 整體表現

| 指標 | 數值 | 說明 |
|------|------|------|
| **R²** | 0.8330 | 解釋 83.3% 的房價變異 |
| **MAPE** | 8.62% | 平均預測誤差約 8.6% |
| **MAE** | 58,829 TWD/坪 | 平均絕對誤差 |
| **RMSE** | 83,374 TWD/坪 | 均方根誤差 |
| **CV R²（5-fold）** | 0.836 ± 0.004 | 模型穩定，無明顯過擬合 |

### 特徵重要性

| 排名 | 特徵 | 重要性 | 說明 |
|------|------|--------|------|
| 1 | 緯度 | 24.88% | 地理位置（南北向） |
| 2 | 類別 | 20.38% | 電梯有無 ＋ 樓層高低 |
| 3 | 經度 | 20.34% | 地理位置（東西向） |
| 4 | 距離（公尺） | 10.18% | 距最近捷運站距離 |
| 5 | 屋齡 | 7.92% | 建築新舊程度 |
| 6 | 坪數 | 4.49% | 建物面積 |
| 7 | 車位坪數 | 3.78% | 停車位大小 |
| 8 | 幾樓 | 3.52% | 所在樓層 |
| 9 | 年份 | 3.43% | 交易年份（反映市場趨勢） |
| 10 | 交易標的 | 0.97% | 是否含停車位 |
| 11 | 是否有電梯 | 0.12% | 與「類別」高度相關 |

> 地理位置（緯度＋經度）合計貢獻 **45.2%** 的預測力，遠超其他個別特徵，印證「地段」是台北市房價的核心決定因素。

| 類別 | 筆數 | 平均每坪（TWD） | 中位數每坪（TWD） |

## 主要發現

1. **地段決定一切：** 緯度與經度合計貢獻 45% 的預測力，是最重要的房價驅動因素。
2. **電梯溢價顯著：** 有電梯高樓（7 樓以上）平均每坪 84.2 萬，較無電梯低樓（4 樓以下）的 62.2 萬高出約 **35%**；較無電梯中高樓（4 樓以上）的 55.1 萬高出約 **53%**。
3. **捷運效應明確：** 距捷運距離貢獻 10.2% 的預測力，交通便利性是重要加值因素。
4. **屋齡影響顯著：** 屋齡貢獻 7.9%，新屋與老屋價差明顯。
5. **市場持續走揚：** 台北市住宅成交均價連續 4 年上漲，累計漲幅達 15.3%。

## 資料欄位說明

### 最終分類資料欄位（`分類篩選/*.csv`）

| 欄位 | 類型 | 說明 |
|------|------|------|
| `交易標的` | 文字 | 例：「房地(土地+建物)」或「房地(土地+建物)+車位」 |
| `地址` | 文字 | 完整門牌地址 |
| `幾樓` | 數值 | 所在樓層（從移轉層次解析） |
| `屋齡` | 數值 | 建築屋齡（年），部分資料可能為空 |
| `是否有電梯` | 0/1 | 1 = 有電梯，0 = 無電梯 |
| `坪數` | 數值 | 建物移轉面積（坪），不含車位 |
| `每坪價格` | 數值 | 每坪成交價格（新台幣），不含車位價格 |

## 注意事項

1. **地理編碼 API 限制：** `geocode_yearly.py` 使用 ArcGIS 免費額度，大量查詢時請注意速率限制，腳本已內建 0.5 秒間隔與本地快取。

2. **原始資料更新：** 內政部每季更新資料，下載新季資料後依序重新執行各步驟即可。

3. **極端值處理：** 模型訓練時去除每坪價格前後 1% 的極端值（共移除 716 筆），以提升模型穩定性。

4. **屋齡缺失：** 部分物件無建築完工年月資料（詳見 `無屋齡資料.csv`），訓練時已以中位數填補。

5. **台灣年份換算：** 資料使用民國年份，換算西元：民國年 ＋ 1911 = 西元年（如民國 113 = 2024 年）。

6. **坪數換算：** 1 坪 = 3.30579 平方公尺。
